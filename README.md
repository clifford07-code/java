The programs cover fundamental to advanced Java concepts, including Object-Oriented Programming, Exception Handling, Collections, Multithreading, GUI development using Swing, and Database Connectivity.

## ▶️ How to Run

### Compile

```bash
javac FileName.java
```

### Run

```bash
java FileName
```

For GUI programs:

```bash
javac GUIProgram.java
java GUIProgram
```

For JDBC programs:

- Install MySQL Server
- Create the required database and tables
- Add the MySQL Connector JAR to your project
- Update the database URL, username, and password in the code before running
